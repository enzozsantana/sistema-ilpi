## Como aplicar no projeto
1. Copie a pasta `public/images/` para a raiz `public/` do seu projeto.
2. Copie `src/pages/LandingPage.tsx` para `src/pages/LandingPage.tsx` (ou ajuste os imports relativos conforme sua estrutura).
